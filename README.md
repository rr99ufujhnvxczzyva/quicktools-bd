# QuickTools BD

QuickTools BD is a beginner-friendly utility toolkit website built with HTML, CSS, and JavaScript.  
It includes multiple useful tools in one place and is designed to help students and beginners use simple web utilities easily.

## Live Demo

https://warm-biscochitos-152c5e.netlify.app

## Features

- Word and Character Counter
- Text Case Converter
- Age Calculator
- BMI Calculator
- Password Generator
- Dark Mode
- Mobile Responsive Design

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Netlify
